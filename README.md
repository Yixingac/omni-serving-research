# Omni Serving Research

**Characterizing and Optimizing Omni Serving Across Heterogeneous Workloads**

Omni serving combines multimodal input processing, language generation, and speech generation. This project studies how workload differences affect hardware use, latency, and throughput, with an emphasis on GPU idle time, stage bottlenecks, and load imbalance.

We will characterize representative workloads before choosing optimizations, then investigate stage placement, disaggregation, scheduling, and resource allocation. The scope includes current audio/video and speech workloads and future real-time multimodal and robotics applications.

**Status:** Research planning. No experiments or benchmark results have been completed for this project. The [roadmap proposal](https://github.com/Yixingac/omni-serving-research/pulls) introduces the detailed plan in `docs/RESEARCH_PLAN.md` for review.

Feedback on workload selection, profiling scope, model/runtime priorities, and disaggregation opportunities is welcome on the proposal PR or in an issue. Future experiments and implementations should use separate, focused PRs with reproducible configurations and clearly labeled results.
