# 用已有数据补写的六个实验：从这里开始

实验 3、4、12、13、14、19 的数据早在 plan v2 的两批 8 卡运行里就跑完了（2026-11-15、11-16，以及 11-17 的补跑），但一直只有零散的表格或一句话结论。2026-11-18 把它们写成了和实验 9–11 同样格式的报告。**没有新的 GPU 运行。**

- 机器：8×RTX A6000。第一批在“第一批节点”（Slurm Job 625796），第二批在 compute-03（Job 454290）。同一种分法换节点，吞吐相差不到 3%。
- 模型 MiniCPM-o 4.5，sglang-omni 520b49ee（没有打实验补丁），输入都是合成数据。

## 先知道三件事

1. **每种配置只跑过 1 次**，所以结论都是“初步”的，没有置信区间。各报告的 `limitations.md` 写了哪些结论可能被随机波动影响。
2. **预测是事先写的，判定方法是事后定的**。实验 12、13、14、19 的预测（D-H1、G-H1、F-H1、B-H1–3）写在 2026-11-11 的计划里，早于任何数据；但“差多少算不同”这类规则是看过数据后才定的，所以判定都是探索性的。实验 19、14 还在看到数据后改过一次规则，`hypotheses.md` 里两种结果都写了。实验 3、4 当初没有预测，全部是描述。
3. **这批报告是在 Mac 上的数据镜像上分析的**。镜像和集群上的原始文件逐个比过文件名和大小，一致。

## 各实验目录里有什么

| 文件 | 内容 |
|---|---|
| `README.md` | 9 个部分：一句话、为什么做、基础概念、请求经过哪里、怎么做、每张图怎么读、证据等级、研究意义、下一步 |
| `hypotheses.md` | 事先写下的预测（原文和提交时间）、事后定的判定方法、判定结果 |
| `limitations.md` | 限制、作废或失败的运行、对结论的影响 |
| `metadata.json` | 每个运行的目录、时间、状态、代码和软件版本 |
| `results/` | 汇总数字，字段见 [数据字典](plan_v2_reports_data_dictionary.md) |
| `figures/` | 图，全部由 `scripts/analysis/expNN_figures.py` 从 `results/` 画出 |
| `reproduce.md` | 怎样从原始数据重新生成结果和图 |
