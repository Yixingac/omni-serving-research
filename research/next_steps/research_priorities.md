## 不建议现在做的

| 想法 | 为什么不做 |
|---|---|
| 写自定义 GEMM 或卷积 kernel | GEMM 和 cuDNN 卷积已经是库实现；低效来自形状、补齐和精度（`compiler_runtime_opportunities.md` 2.1） |
| 在当前合成 Agent 上比较缓存驱逐策略 | 工作集远低于容量，任何策略都等价于 LRU（实验 19） |
| 搬 FlashStates 的 checkpoint 机制 | MiniCPM-o 的 thinker 没有循环状态 |
| 直接部署 ThunderAgent 代理 | 代理不了 WebSocket 和阶段交接；目标是吞吐，不是首段音频 |
| 把实验 11 的旁路复制当作可用优化 | 正确性门槛没有通过 |
| 拿 GB10 的数字和 A6000 比 | 仓库约定禁止；GB10 只用于功能和工具验证 |
