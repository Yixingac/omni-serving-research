# research/：按编号组织的研究记录

这个目录用中文记录 SGLang-Omni（MiniCPM-o 4.5）在 8×A6000 上的研究：每个研究问题一个编号，每个编号一个目录。

## 怎么读

1. [实验总目录](实验总目录.md)：每个实验在问什么、做到哪一步、关键结果是什么。
2. [当前系统和已有实验说明](00_当前系统和已有实验说明.md)：请求怎么走、8 张卡怎么分工、有哪些工具、还缺什么数据。
3. 各实验目录里的 `README.md`：按统一的 9 节格式写，先讲概念和结论，再讲细节。

## 每个实验目录里有什么

| 文件 | 内容 |
|---|---|
| `README.md` | 中文报告：一句话解释 → 为什么做 → 怎么运行 → 测什么 → 结果 → 原因 → 意味着什么 → 下一步 → 文件在哪里 |
| `metadata.json` | 编号、内部配置 ID、Slurm Job、代码版本、用到的运行目录 |
| `figures/` | 图，由脚本生成 |
| `results/` | 汇总数字（JSON），报告里的数都从这里来，由脚本生成 |

原始数据不放在仓库里（体积大，而且带机器名和路径），在集群的 `results/experiments/` 下；Mac 和 Spark 上有镜像。

## 结论的标注

| 标注 | 意思 |
|---|---|
| 实测 | 直接测到的数 |
| 推算 | 由实测的数算出来的 |
| 假设 | 还没验证的解释 |
| 未知 | 现有数据回答不了 |

只跑过一次的结果标“初步”。
