# 实验 19：限制、失败和对结论的影响

1. **每种配置只跑了 1 次**。没有重复，就给不出置信区间，所有结论都是初步的。
   - 能参考的只有纯语音数据里的重复：同一种分法多数相差不到 3%，最大 5.6%（4+4）。
   - 混合负载里 3+5 比第二名高 8%，文本 Agent 里 8 个完整副本的会话中位数比第二名短 26% 以上（256 个会话时 2.92 对 3.98 秒），都大于这个范围。但语音 Agent 在 256 个会话时，4 组 1+1 和 4+4 只差 4%，分不出高低。
2. **两批在不同的节点上**。2+6、4 组 1+1、8 个完整副本的混合负载在第一批节点上跑，3+5、4+4、5+3、6+2 在 compute-03 上跑。
   - 两台都是 8×A6000，但驱动不同（570 + cuda-compat 和 580）。
   - 同一种分法换节点，纯语音吞吐相差不到 3%（第二批报告第 5 节，2+6 和 8 个完整副本）。混合负载没有做跨节点的对照。
   - 最好的 3+5 恰好在 compute-03 上。如果 compute-03 系统性地快 3%，3+5 仍比第二名高约 5%，排序不变。
3. **“闭环最高吞吐”其实是“并发 256 时的吞吐”**。7 种分法的最大值都出现在测到的最高并发 256，真实的上限可能更高，排序也可能变。
4. **开环比不出高低**。开环的速率是每种分法自己闭环最高吞吐的 0.5–1.2 倍，不是同一组绝对速率。除 6+2 外，所有分法到 1.2 倍时仍有 ≥ 99% 的请求满足 SLO（6+2 在 1.2 倍时只有 67.8%），所以开环只说明“闭环低估了容量”，不能用来排序。
5. **判定方法是看过数据后定的**，见 hypotheses.md 第二、三节。其中参照的规则在看到容差 6% 的结果后改过一次，改动对 B-H1、B-H2 有利。
6. **Agent 部分只有 4 种分法**（8 个完整副本、2+6、4 组 1+1、4+4）。3+5、5+3、6+2 没有 Agent 数据，所以“Agent 下最好的分法”只是这 4 种里最好的。
7. **Agent 每档实际只有 15–85 秒**（配置说明写的是“约 2–3 分钟”）。每档的开头有升温、结尾有收尾，算在统计里。第一批每档只有 4–40 秒，只用来对照方向，没有进入判定。
8. **和计划不一样的地方**：
   - 计划写的是在“最好的配置上”做工具延迟三档，实际在 2+6 上做的。2+6 对文本 Agent 是最差的分法，所以图 7 只说明“2+6 上工具延迟的影响”。
   - 计划写的“两个 profiler 窗口”没有做。
   - B1 计划只用 8 个完整副本和纯语音最好的两种分法，第二批多加了 4 种池化分法。
9. **失败的请求**。混合负载 7 个运行、107,843 个请求全部成功。Agent 加长版里有 36 个请求因为 GPU 显存不足（CUDA out of memory）失败：
   - 8 个完整副本 4 个（语音 Agent 128 个会话 3 个、256 个会话 1 个）。
   - 4+4 32 个（语音 Agent 256、512 个会话各 16 个，都在 GPU 6、7 上，一次要申请约 8.9–9.2 GiB）。
   - 4+4 的语音 Agent 在 256 个会话时会话 P90 跳到 19.4 秒，可能和这些失败有关（Hypothesis）。这两档 4+4 的尾延迟不宜和其他分法直接比。
   - 另外，任务成功率是 98.8%–99.8%。没成功的会话是模型答错或没按格式调用工具，不是服务出错。
10. **合成任务的局限**。每个会话中位数只有 2 次模型请求，所有会话共用同一段系统提示词和工具说明。所以前缀缓存的命中主要来自共用部分，按会话固定路由几乎没有用武之地。真实 Agent 的会话更长、每个会话自己的上下文更多，B-H3 的结论可能不同。
11. **“名额”的解释没有验证**。thinker 默认最多同时处理 64 个请求，这个数取自 sglang-omni 520b49ee 的源码（`stages.py` 第 361 行）。服务日志只打印了 talker 的上限（32），没有打印 thinker 的；我们的配置没有改它。TTFT 在并发超过“副本数 × 64”时变长，和这个解释相符，但没有用改大上限的运行验证。
12. **GPU 忙碌比例只说明有没有 kernel 在跑**（nvidia-smi 采样），不说明算力用满了没有。“2+6 的 thinker 卡只忙 64%”说明它没有一直在算，不说明它还能再算 36%。
13. **混合负载的比例是固定的**（40% W1、40% W3b、20% W2），别的比例没有测。
